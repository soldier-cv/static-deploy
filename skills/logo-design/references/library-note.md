# 参考库说明（分发版不含）

完整技能自带 1400+ 真实品牌 SVG 参考库（assets/，14MB），因体量与商标限制未随本分发版发布。

- 上游仓库：https://github.com/kaankiziltug/logo-design-skill（MIT；assets/ 参考库不在 MIT 内，仅限学习参考，商用需自行做商标检索）
- 本机已装完整版的 agent：`search_library.py` 直接可用。
- 未装完整版的 agent：跳过 `search_library.py` 步骤，按 references/ 里的设计原则执行即可；`svg_audit.py` / `preview_sheet.py` / `export_variants.py` 等脚本不依赖参考库，全部可用。
